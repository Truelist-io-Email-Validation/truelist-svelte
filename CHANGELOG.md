# Changelog

## 0.1.0 (2026-02-20)

- Initial release
- `truelist` Svelte action for adding validation to any input
- `createEmailValidation` store for headless state management
- `EmailInput` pre-built component with data attributes
- `TruelistProvider` context provider for shared configuration
- API client for Truelist form_verify endpoint
- TypeScript support with full type exports
- Supports Svelte 4 and Svelte 5
